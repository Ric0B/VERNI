One-offs

In the Gletscher lamp, a single number decides where the crevasses run. We call it the code. Every code gives a different pattern, and we print each code exactly once. Here are three of them.

Your own code

CHF 690

A wedding date, a birthday, the postcode of a first home together: we compute your pattern from any number. You see a preview before printing and can say no. After that, the code is locked and never given out again.

  1. Choose a code

    Send us a number, or let us draw one at random.

  2. Preview

    Within 2 days you get images of your pattern, switched on and off.

  3. Print

    We print your lamp in 6 hours, test it for 4 hours and assemble it by hand.

  4. Certificate

    Code, print date, layer count and an unrolled drawing of your pattern, signed.
